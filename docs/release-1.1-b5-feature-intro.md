## 一句话摘要

优化训练页在历史记录较多时的操作体验，完善动作库，并修正登录失效时进入 Team 的错误处理。

## 面向测试用户的更新说明

- **训练操作优化**：当前训练先可操作，历史统计在后台准备；减少历史记录较多时输入与完成训练组的等待，避免历史加载覆盖正在编辑的数据。
- **休息交互优化**：调整休息计时入口与键盘展开时的交互，改善训练过程中填写数据与查看休息时间的体验。
- **动作库完善**：新增 Y字侧平举、单侧器械侧平举、低位坐姿划船机。三个动作暂不提供动作示意图；更新胸托 T 杆划船示意图，肩部肌群缩略图采用透明背景。

- **登录失效处理修复**：修正登录失效时进入 Team 等页面的笼统 403 错误，使用客户端已有的重新登录流程。后端现已生效；真实权限不足不属于本次修复范围。

## 内部技术变更

- 历史读取与聚合异步化，引入明确的历史准备状态，减少主线程负担；训练输入与历史快照更新隔离。
- 调整完成组后的持久化/刷新路径及休息提醒初始化，保留离线优先与待同步队列。
- 后端 `SecurityConfig` 使用 `HttpStatusEntryPoint(401)`；未认证与已认证但无权限的 403 分离，增加安全配置测试。
- 上述后端修复已部署，线上未登录及无效 JWT `/teams` 返回 401；不代表所有权限不足问题都会消失。
- 本次无新增数据库迁移，无新 API 契约或身份数据迁移；生产当前 Flyway 为 22。
- 预设动作、兼容名称与 Swift 兜底条目同步更新；三项无图决策纳入资源覆盖台账。胸托 T 杆划船使用已确认母版，记录真实生成输入来源。
- 肩部肌群导出改为透明背景；运行时 JPG 仅用于有正式动作图的条目。
- 所有 8 处 build 配置由 4 递增为 5，版本号仍为 1.1。
