# 固定辅助重量规则

本次仅将稳定代码 `ASSISTED_PULL_UP`（辅助引体向上）设为公斤助力动作；普通引体、高位下拉、自定义动作以及弹力带、凳子、TRX 支撑辅助不自动套用。无用户配置入口。

## 录入与统计

- 保存正数辅助公斤；0 为明确无辅助，空值为未记录。不倒算体重，不把数据改成负数。
- 训练动作卡底部提示“此动作记录辅助重量，辅助越小，难度越大。”；计划、历史、Live Activity、海报和新 Team 摘要明确显示辅助含义。
- 辅助公斤数的负重吨位贡献为 0，正式组、次数、肌群组数及热量算法保持。普通组与递减分段共享统计投影。
- 辅助 PR 要改善一条旧成绩（辅助更少、次数不少），且不能被另一条旧成绩覆盖。首次建基线，同辅助仅增加次数不算重量突破，每动作每场至多一次；只比较此前训练。
- 最低辅助摘要和新 PR 不等价；低辅助低次数记录可以展示，但不能自动宣称突破。
- 计划逐组原值不变，代表值采用最低辅助；替换动作仍沿用目标动作历史/清空规则，递减段不重排。

## 数据与兼容

- 训练继续同步现有 code 和 weightKg，不新增 schema 或可编辑重量模式。
- Team 新摘要添加可选 builtinExerciseCode；旧摘要可以解码，缺少代码时不按名称猜测，不主动重发历史打卡。
- Team 分享/Fork 仍剥离全部个人重量，保留动作身份。
- 成就尚未上线：一次性按规则版本后台重算，再原子替换旧授予。失败不标记成功，重试；规则升级成功后恢复永久授予，重复启动不重置。原始训练不删除、不改写。
