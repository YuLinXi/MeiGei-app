## 验证结论

以下汇总2026-11-07至09日已经执行的检查，本次文档整理没有重跑。原始临时结果的保留边界见[清理结果](#清理结果)。

- **编译：** 最新受影响源码的 Debug 测试包与通用 iOS Simulator Release 主 App／widget 编译通过。Release 为未签名模拟器编译，不是设备 Archive 或真机验收。
- **单元与持久化：** 取消语义修复对应的 iOS17.4、26.5完整单元各412个方法／496次运行通过，失败及跳过均为0；包含独立 SQLite 红绿回归。后续备注布局和测试等待调整未改变该保存实现，复用对应业务证据，没有重跑最新 UI 候选的完整套件。
- **计划输入：** 最低17.4复用默认／最大字号定向结果与非 XCTest 正常进程实际操作；已确认中心点击恢复焦点、稳定输入完整保留、保存重开逐字一致，收键盘后分组可选择并回填。当前26.5最大字号的新建、基础信息和独立备注三条 UI 用例通过，失败／跳过均为0，覆盖失败保留草稿、重试、取消和重开比对。
- **原有自动化失败：** 最低系统旧批次的大字号备注快读失配、分组按钮完整边界断言仍按失败记录；正常进程验证不将旧批次改成全绿。本轮不继续扩大输入工具排查。
- **同步性能：** 子树复用后80轮数据与落盘断言通过；同一小屏26.5 Debug隔离环境中，5000条已有训练更新中位数由约51.624秒降至32.429秒，下降约37.2%。保留一次122.066ms最长调度间隔异常；采样未对齐，不能直接归因于某次保存，也不能据此宣称帧率、能耗或真机响应达标。
- **测试框架定位：** iOS17.4曾捕获 `XCTAutomationSupport.runtime_issue_os_log_fault_callback` 的 `strcmp` 空地址异常，仅在临时 UI 测试配置中使用 `OS_ACTIVITY_MODE=disable` 并核对目标进程。无对应堆栈的其他退出不一并归类，正式 App 和全局日志配置不变。使用边界见[开发与验证指南](development.md)。
- **规格与差异：** 相关 change 的 strict 校验及差异检查已有通过记录；本次只核对文档、引用和差异。规格结构通过不等于全部业务、设备或发布门禁通过。

以上编译、业务测试和隔离 UI 证据分别有效，不合并表述为真实后端、跨设备或端到端全链路通过。

## 活动休息验收

2026-11-08，iPhone SE（iOS26.5）隔离测试库中，完成一组后将休息由300秒增加至310秒，在仍剩244秒时结束训练。完成页显示5:10，同一组的 `plannedRestSeconds` 与 `actualRestSeconds` 均为310，停止 App 后只读复核仍保留。该结果覆盖训练结束回填目标总时长，不包含真实同步、通知投递或 Live Activity 系统侧验收。对应[活动休息任务](../openspec/changes/finalize-active-rest-with-target-duration/tasks.md)6/6项完成。
