## 2. 本次功能范围

### 力量成就勋章与生涯回顾

- [x] 在「我的」页面新增常态化成就勋章馆，展示力量突破、训练吨位与坚持天数三大分类。
- [x] 支持三大项（卧推、深蹲、硬拉）相对自身体重倍数突破勋章（如 1.0x、1.5x、2.0x）。
- [x] 支持生涯总吨位里程碑勋章与坚持天数勋章，支持本地判定与存量训练数据静默回溯。
- [x] 新版本首次启动展示沉浸式生涯突破回顾卡片；训练中刷新纪录解锁新勋章时提供突破庆祝卡片。

### 肌群周负荷复盘（OpenSpec `add-weekly-muscle-load-review`，已归档）

- [x] 训练首页新增过去 7 天肌群周负荷复盘卡片，直观呈现胸、背、腿、肩、手臂等各大肌群的刺激强度与组数分布。
- [x] 协助训练者判断本周各部位是否均衡、是否存在肌群遗漏，支持与动作库肌群导航联动。

### 计划备注与动作要点备忘（OpenSpec `add-plan-notes`，已归档）

- [x] 训练计划支持添加整体周期与阶段备忘。
- [x] 计划中每一个动作和训练单元支持添加独立的动作要点提示。
- [x] 计划保存为模板、复制、团队内分享与导入完整保留备注。

### 训练与计划就地排序

- [x] 训练进行中与计划编辑页统一采用就地排序面板，点击「调整训练动作顺序」直接就地展开。
- [x] 背景全屏蒙层防误触，支持拖拽手柄直观排序，点击完成立即保存。
- [x] 训练卡片折叠箭头移至头部左侧，更多操作菜单居右。

### 辅助动作真实有效负荷修正

- [x] 修复 `v1.1-b2` 中辅助自重动作（如辅助引体向上）配重板重量被当成外加负重的语义错误。
- [x] 输入框明确标注为「配重板辅助重量（减重）」，系统自动按「体重 - 辅助重量」计算真实有效做功负荷。
- [x] 训练吨位、PR 纪录与力量勋章全面适配真实有效负荷计算。
