## 一句话摘要

把历史训练快速整理为个人计划，并改善保存与同步反馈、大字号阅读和训练过程中的操作衔接。

## 面向测试用户的更新说明

1. **历史训练另存个人计划。** 从首页最近训练或历史日历打开自己的已完成训练，在更多菜单选择“另存为个人计划”。可以调整名称、备注、模式和分组；普通动作与递减组保留本次已完成的逐组内容、热身、备注和休息配置。保存为独立私有计划，原训练及来源计划保持原样。
2. **保存与同步更有反馈。** 训练、计划、自定义动作及资料提交失败时提供恢复和重试，保留相应输入；画像恢复失败后可重新尝试或返回登录。资料页区分上次同步成功、部分失败与失败，帮助判断下一步操作。
3. **大字号和输入更易用。** 核心页面跟随系统字号，调整文字对比度、按钮触达和辅助功能语义；改善计划名称／备注、普通／递减／超级组编辑的键盘布局、动作库索引及徽章阅读。
4. **训练操作衔接更顺畅。** 已有训练时突出继续并提供明确取消；排序可取消，确认后才保存。调整浮动训练入口避让及训练结束后的反馈顺序，可重新查看本次保留的计划更新回执。
5. **历史与 Team 状态更清楚。** 优化大量训练记录同步和读取，避免将加载或失败误显示为没有记录；明确 Team 默认分享及取消／撤回说明，取消分享选择不会改变已有可见性。

上述为候选已实现的行为，待安装 TestFlight 后按 checklist 验收，不表示已上线。真实边缘返回与真机系统能力仍待确认，不承诺已完整修复所有导航或辅助功能问题。

## 内部技术变更

- 历史另存复用普通计划编辑与 `WorkoutPlan.items`，独立生成计划及条目身份，沿用待同步队列和既有同步信封。转换只处理本次训练，不读取来源计划补回未练内容。
- 增强明确保存的成功反馈与失败恢复，候选插入使用同一 container 的独立 context；取消已失败的基础信息编辑后，草稿不会随其他保存意外提交。项目保存事件兼容最低系统的缓存刷新边界。
- 同步响应保护上传期间的本地修改、删除墓碑与当前会话；可靠保存后才推进水位。新建／重建本地库不沿用旧库增量水位，相同训练子节点按稳定身份复用，避免重复替换造成关系异常。
- 训练下拉按有界根窗口与完整聚合批次保存，在批次间让出执行器并复核会话；历史／徽章的模型字段复制与写入串行，后台继续处理值快照。
- 公共字体按角色单次缩放，增加可读操作色，完善原生输入、辅助功能动作、加载状态与浮层约束；固定海报画布继续使用独立字号边界。
- 测试 fixture、故障注入与本地开发账号登录用于隔离验证；不新增生产 API、登录方式、数据库迁移或依赖。正式 Release 仍指向生产 HTTPS，开发 token 默认关闭。
- 隐私和条款已对齐创建／加入 Team 后默认开启分享的既有服务端行为，源文件及线上正文一致。默认偏好并非本次新增开关。
- 动作库数据、动作图、manifest 相对已发布基线无差异；本次颜色资源调整不属于动作图更新。

## 兼容性与发布顺序

最低系统保持 iOS 17.4。CloudKit 保持关闭；离线优先、JWT Keychain、幂等键、聚合 LWW、软删除及 Team 服务端裁决规则沿用现有契约。没有新增 Flyway 迁移，生产当前最新成功版本为 V22。

历史另存所得计划按普通计划使用。默认自适应模式下，“下次训练安排”仍可能受其他历史影响；用户可自行选择严格模式。超级组继续保留统一成员安排与既有轮数，未新增逐轮不同值的预填或回写。

候选版本已冻结推送，法律页面公网正文已发布并复核；App 内入口、App Store Connect URL 与手动边缘返回门禁仍待完成，再执行签名 Archive／TestFlight。等待 `VALID`、真机主路径通过及用户确认后，才合并 main 和打 tag。本轮未 Archive、上传、合并或创建 tag。

后端应用服务可维持现状；如果执行阶段同时部署应用源码，只用 `release-update.sh` 并完成对应门禁。该脚本不会更新 Caddy 实际挂载的 `/opt/stacks/edge/site`，法律文件必须单独发布核对，HTTP 200 不代表正文对齐。

## TestFlight 回归重点

1. 从已安装版本升级，确认历史、计划和自定义动作保留；真实 Apple 登录、冷启动及画像恢复可继续。
2. 从首页／日历各另存一份历史训练，核对逐组差异、热身、递减组、备注、休息、所选分组；取消不新增，成功后原记录不改名，计划可继续训练。
3. 大字号下编辑名称、备注、普通／递减／超级组；键盘打开后仍能看清字段和操作。真实执行计划动作区的边缘返回、展开／收起和编辑后返回。
4. 当前训练中修改数值、继续／取消／丢弃、四类排序取消／确认；结束后关闭计划更新、PR 与徽章，重看回执和撤销均可按预期完成。
5. 离线保存后恢复同步；同步期间继续录入或丢弃训练，检查记录不复活、不丢组、不重复，失败状态可重试；再验证另一设备的最终结果。
6. Team 加载、失败重试、分享取消与显式撤回；真实通知、锁屏、Live Activity、HealthKit 和 widget 的受影响路径。
