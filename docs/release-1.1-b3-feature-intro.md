## 一句话摘要

本次版本带来专注力量突破与训练积累的严肃成就勋章系统与生涯回顾，新增肌群周负荷复盘卡片与计划/动作全链路备注，统一了训练与计划中的就地排序体验，并修复了辅助动作真实有效负荷的统计与 PR 计算。

## 面向测试用户的更新说明

以下内容只汇总相对上一个已发布版本 `v1.1-b2` 的最终用户可感知差异。

### 1. 严肃力量训练成就勋章与生涯回顾

- **荣誉勋章馆**：在「我的」页面新增常态化勋章馆入口，集中展示全部力量突破成就、当前达成进度与解锁状态。
- **力量突破勋章**：专注三大项（卧推、深蹲、硬拉）相对自身体重的硬核突破，设立 1.0x、1.5x、2.0x 体重等里程碑。
- **训练积累勋章**：记录每一次踏实的积累，包含生涯总训练吨位里程碑（如 100 吨等）以及坚持训练天数成就。
- **沉浸式回顾与突破庆祝**：新版本首次启动支持浏览过往训练汇聚的生涯突破回顾；训练中刷新纪录并解锁勋章时，结算页提供仪式感十足的勋章突破弹窗。

### 2. 首页肌群周负荷复盘

- **过去 7 天肌群负荷分布**：在训练首页新增肌群周负荷复盘卡片，按胸、背、腿、肩、手臂等主要肌群直观展示本周有效组数与刺激强度。
- **训练均衡度概览**：帮助严肃训练者快速复盘本周各部位负荷是否均衡、是否存在肌群遗漏或过度训练，合理规划下一次排课。
- **动作库肌群导航联动**：浏览动作库时支持按目标肌群清晰筛选与检索，方便根据复盘结果快速补充动作。

### 3. 计划备注与动作要点备忘

- **计划整体备注**：可在训练计划中添加周期目标、训练注意事项或阶段性安排等整体备忘。
- **单动作与单组备注**：计划中的每一个具体动作和训练单元均支持记录独立的动作要点（如握距、意念连接或节拍提示）。
- **全链路保留与分享**：保存计划模板、复制计划、在 Team 团队中分享与导入计划时，均完整保留计划与动作备注。

### 4. 训练与计划统一就地排序体验

- **全新就地排序模式**：在训练进行中与计划编辑页点击「调整训练动作顺序」后，直接在当前位置进入轻量高效的专注排序面板，背景蒙层防止误触其他操作。
- **直观拖拽排序**：拖拽右侧手柄即可自如调整动作先后顺序，点击「完成」立即保存，无需跳转额外页面。
- **卡片浏览优化**：训练进行中长动作卡片的折叠箭头统一部署于头部左侧，更多操作菜单居右，浏览长计划更清晰整洁。

### 5. 辅助动作真实做功负荷与体验修复

- **统一辅助重量语义**：修复了此前版本中辅助自重动作（如辅助引体向上、辅助双杠臂屈伸）将插销配重错误当成外加负重统计的问题。
- **真实有效负荷计算**：输入框明确标注为「配重板辅助重量（减重）」，系统自动按「当前体重 - 辅助重量」换算真实做功负荷；训练吨位、个人 PR 纪录以及力量勋章进度均准确反映真实力量表现。

## 内部技术变更

- **后端数据库迁移**：
  - `V21__workout_plan_note.sql`：在 `workout_plan` 表新增 `note` 字段；在 `team_plan_share_version` 表新增 `plan_note_snapshot` 快照字段，保证团队分享历史幂等不变。
  - `V22__workout_body_weight_snapshot.sql`：在 `workout` 表新增 `body_weight_kg_at_completion` 字段，用于记录训练完成时刻的用户体重快照，确保历史辅助动作有效负荷不因未来体重波动而发生漂移。
- **后端服务与测试扩充**：
  - `WorkoutPlanService` 与 `TeamPlanService` 支持计划备注读取、保存、LWW 增量同步与分享快照。
  - `WorkoutService` 增加训练结算时体重快照落盘逻辑。
  - 后端测试用例由 80 项扩充至 89 项，新增 9 项覆盖 V21/V22 的增量迁移、备注更新、空值安全与快照测试，全部通过。
- **客户端架构演进**：
  - 勋章核心架构：引入 `BadgeEngine`、`BadgeDefinition`、`BadgeWallStore` 与 `BadgeCelebrationCenter`，实现本地高效判定、静默自愈回溯与防重复提示机制。
  - 肌群负荷计算：引入 `MuscleLoadAggregator`，高效聚合过去 7 天非软删训练记录并映射解剖学肌群部位。
  - 通用排序组件：封装 `InPlaceReorderPanel`，训练中与计划编辑统一复用，减少冗余手势与列表交互逻辑。
- **规格与测试工程**：
  - OpenSpec 规格归档：`add-plan-notes` 与 `add-weekly-muscle-load-review` 两个 change 规格已正式归档。
  - UI 测试稳定性：重构 `UITestHooks.seedLiveWorkoutIfNeeded`，改为启动期确定性清理与重置会话，彻底消除自动化测试用例间的跨用例数据污染。

## 兼容性说明

- **后端先发完全向后兼容**：后端已先行部署上线并应用 Flyway V21 与 V22 迁移。所有新增数据库字段均为可选/可空字段，未升级的旧版客户端（`v1.1-b2` 及更早）可无缝继续登录、同步和记录训练。
- **端侧新功能生效范围**：成就勋章馆、肌群周复盘卡片、计划整体/动作备注、统一排序面板以及辅助动作精准负荷语义需安装 `v1.1-b3` 客户端后生效。
- **多设备同步注意**：若同时在多台设备登录，旧版客户端若在修改计划后上传，由于旧版数据模型不识别 `note` 字段，可能会发生 LWW 覆盖丢失备注，建议常用设备统一更新。

1. **成就勋章与生涯回顾**：
   - 进入「我的」页面点击成就勋章卡片，检查勋章馆各分类（力量突破、训练吨位、坚持天数）展示与当前数值进度。

3. **计划备注**：
   - 创建或编辑计划，为计划添加整体备注，并为动作添加独立备注；保存后重新进入核对内容是否完好。
   - 将该计划分享至 Team 或复制为新计划，确认导入方能完整看到备注。
4. **就地排序交互**：
   - 在训练进行中点击「调整训练动作顺序」，拖拽调整动作顺序并保存，确认训练列表顺序实时生效且背景蒙层正确封锁误触。

   - 在训练中添加「辅助引体向上」，记录不同配重板重量，检查组行提示文字（辅助越小难度越大），并在结算后确认详情吨位与 PR 按照「体重 - 辅助重量」计算。
