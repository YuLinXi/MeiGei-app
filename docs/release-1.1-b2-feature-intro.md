## 一句话摘要

本次版本让训练计划记住每个动作的休息设置并自动带入下一次训练，同时把休息计时弹窗和训练历史详情改得更轻、更好用。

## 面向测试用户的更新说明

以下内容只描述相对已发布版本 `v1.1-b1` 的最终用户可感知变化。

### 计划记住休息设置

- 计划中的普通动作和递减组可以单独设置默认休息：跟随全局、关闭自动休息，或从常用秒数、自定义秒数中指定具体时长。
- 从个人计划开始训练时，每个动作的休息设置会自动带入；从 Team 分享的计划直接开始或 Fork 后同样保留。
- 自适应计划完成训练后，本次显式配置的休息会和组数、重量、次数一起写回计划，并展示回执、支持撤销；严格计划不做自动回写。
- 保存为计划模板、复制计划等路径都会保留休息设置。
- 训练中调整动作休息时，可以随时一键恢复为「跟随全局」。

### 休息计时弹窗改版

- 休息计时从全屏页面改为屏幕中央的悬浮卡片，不再遮挡整个训练页。
- 点击卡片外的灰色遮罩即可收起计时回到训练页，计时继续运行，随时可从右下角悬浮按钮重新展开。
- 卡片右上角保留最小化按钮；底部震动、声音开关简化为纯图标样式。

### 训练历史详情更好读

- 训练详情的动作卡片和超级组卡片现在可以点击标题收起或展开，浏览长训练记录时更清爽。
- 递减组卡片增加了结构图标，与普通动作一目了然。

### 其他修复

- 修复「保存为计划」时修改的名称不同步到本次训练记录的问题：现在保存后训练历史中的名称会与计划名称保持一致。

## 内部技术变更

- `PlanItem` JSON 增加可选 `restAfterSetSeconds` 字段，语义为缺失跟随全局、`0` 关闭自动休息、正整数显式秒数；继续复用 `WorkoutPlan.items` jsonb 与既有 LWW 同步信封，后端透明保存，无 schema、API 或 Flyway 变更。
- 自适应 `PlanWriteback` 按一级训练单元合并默认休息，rest-only 变化会触发回执与撤销；只使用训练单元默认休息作为回写来源，不用实际休息用时或单次倒计时调整自动学习计划默认值。
- Team 分享快照与 Fork 的客户端重建逻辑在剥离作者重量时保留休息键；后端仅更新 `TeamPlanServiceTest` 测试覆盖。
- 休息计时弹窗从全屏 overlay 改为根层居中卡片浮层，遮罩为独立命中区；计时状态与展示状态继续分离，收起不影响计时。
- 已知兼容风险：旧客户端（`v1.1-b1` 及更早）编辑并保存同一份计划时，因不认识新字段，重新上传的 items JSON 会丢失休息设置（LWW 覆盖），已记录待后续多设备策略处理。

## 兼容性说明

- 本次不需要先发后端。现有生产后端可以同时服务 `v1.1-b1` 和 `v1.1-b2` 客户端。
- 新增的计划项休息字段是现有 JSON 中的可选字段。旧客户端会忽略该字段，新客户端在字段缺失时继续跟随全局默认休息。
- 计划休息设置、休息计时卡片浮层、训练历史卡片折叠和名称同步修复都需要安装 `v1.1-b2` 客户端后生效。
- 注意：未升级的旧客户端编辑并保存同一计划会丢失休息设置，多设备用户建议同时升级。

## TestFlight 回归重点

1. 在计划编辑中为普通动作和递减组分别设置「跟随全局」「关闭自动休息」「显式秒数」，从计划开始训练，确认休息计时时长与设置一致。
2. 用自适应计划完成一次训练并显式调整休息，确认回执包含休息变化、写回计划正确且撤销后恢复原值；严格计划完成训练后确认不回写。
3. 验证保存为模板、复制计划、Team 分享直接开始与 Fork 后，休息设置均保留；训练中通过休息菜单恢复「跟随全局」。
4. 覆盖休息计时卡片：点击遮罩收起、FAB 重新展开、右上角最小化、震动/声音图标开关、自然结束与提前结束提醒（含 Live Activity）。
5. 打开训练历史详情，收起/展开动作卡和超级组卡，确认递减组图标与 PR 标记、备注展示正常。
6. 将一次训练「保存为计划」并修改名称，确认历史记录中的训练名称同步更新。
7. 使用 `v1.1-b1` 客户端连接当前生产后端完成登录、拉取和训练同步，确认后端兼容未升级用户。
