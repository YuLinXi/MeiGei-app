# Design

## Context

动机见 proposal。当前 `Theme.Font.display/body` 使用固定系统点数，`mono` 的自定义字体会缩放、回退分支却固定；计划详情还有三处已预缩放值。既有默认排版采用系统中文／正文和 JetBrains Mono 数据，层级由字号、字重、空白及暖灰共同承担，适合记录型 Operate 页面，保留家族与默认密度。

独立机械检查覆盖 120 个 Swift 文件，正则命中 189 处直接 system size、475 处 Theme 任意 size、68 处单行和 33 处缩小比例，包含图标和导出画布，不能直接算缺陷数量。网页 type detector 返回空数组，未提供 SwiftUI 语义证明。公共 Sheet 74×44 按钮／96pt 标题占位、菜单 232×52 及其高度预计算、32pt Chip 和训练数值格需随字体一起核对。

本轮色值计算显示：muted 在纸白／白卡上约 2.70／3.02，原 accent 在纸白约 3.82、与白字约 4.28，ok 在白卡约 3.51；不以品牌色名称推定可读。S1 恢复页面的默认字号渲染是当前界面依据，完整大字矩阵尚待执行。

## Goals / Non-Goals

建立一次缩放、可读色和可操作语义的公共路径，按页面实测修复其约束。保留纸感浅色、原品牌朱砂装饰和五个模块，不增加数据模型或依赖；身份三层、幂等键、同步信封、墓碑、LWW 和聚合边界均不变。性能只记录本次结构风险与定向证据，完整 trace 仍在 S4。

## Decisions

1. **字号角色在 Theme 收口。** 以轻量字体描述值记录基准尺寸、系统文本角色、字重与字体来源，统一字体修饰符通过 ScaledMetric 解析当前环境，再构造固定于已缩放尺寸的系统／自定义字体。沿用调用点的 Theme 入口；相较逐页补倍率，避免两套缩放规则。最低系统 17.4，不依赖 26 新增的 Font 缩放 API，不使用私有系统字体名称。
2. **缩放一次且可实测。** 中文、注册 Mono 与系统等宽回退共用相同角色解析；移除 PlanDetail 传入字体的已有预缩放，保留其布局所需环境判断。用真实 SwiftUI 文本测量与渲染验证默认／XXXL／accessibility XXXL；检查固定画布边界，避免海报整体跟随设备字号而溢出。
3. **可读色不替换品牌装饰。** 保留原 accent 与浅底，新增同源深朱砂 action 色用于可读操作文字及白字按钮；加深 muted 和成功色。先用资源实际 sRGB 计算纸白、白卡、暖底及实际组合，再检查 rendered states。装饰边框与禁用状态单独识别，不把其低对比误报为正文。
4. **真实语义与触达配套。** 优先用 Button/Toggle 及明确标签，保留必要的复杂手势，仅对其补可执行语义。圆钮保留 36pt 视觉、外扩到 44pt；不让相邻点击区域重叠。Sheet 根据字号采用可增长或纵向操作布局；菜单定位与实测尺寸共同修改，不只放大字体。
5. **按核心任务检查页面。** 公共组件修复后，依次核对首页／历史、训练录入／休息、计划编辑、动作库／创建、Team 和资料页。大字号或长数值暴露的问题就地修改，保留 S1 的可靠保存和原生边缘返回。导出画布和系统导航的字体例外逐项记录。
6. **完整索引兼顾触达与手势。** 右侧索引实测可点击宽度约 28.75pt。每项扩大至至少 44pt 后，有限高度不足以同时展示全部项目，使用独立纵向滚动容器；轻点仍直接选择，稳定按住 150ms 后可连续拖选，短滑用于浏览。用真实拖动及首尾项目操作验证不会误开卡片或在滚动时意外筛选。辅助功能大字时卡片单列、名称完整换行；筛选数据源、code、历史归并和查询规则不变。
7. **窗口变化保留输入焦点。** 聚焦期间两种动效模式共用局部键盘视口观察器；普通模式仅在聚焦行未完整可见时校正，并沿用焦点切换的 0.25 秒 easeOut，减弱动态效果时直接定位。真实窗口缩窄后继续编辑同一单元，不清空焦点或收起键盘；不增加全页逐帧订阅、历史读取或数据模型。
8. **超级组数字表单按实际视口定位。** iOS 17.4 的小屏最大字号手动操作暴露：键盘使用外层 safeAreaInset 时，居中定位的字段上边缘仍被页头遮挡。键盘与 ScrollView 改在同一纵向容器中分配高度，沿用计划动作编辑器的布局方式，让滚动定位基于扣除键盘后的实际区域。辅助功能字号下展开键盘时，页头上留白由16pt收紧到4pt，为字号更大的统一组数字段保留完整空间；字号、按钮触达、输入与统一轮数规则保持不变。

9. **替换返回项，不禁用原生返回语义。** iOS26.5的同一原生UIKit对照中，默认代理和现有自定义代理均能完成CLI边缘返回；仅设置`hidesBackButton=true`后失败，恢复false后再次通过。原计划详情作同样运行时对照亦恢复，单独移除代理没有效果。公共容器不再声明`navigationBarBackButtonHidden(true)`；桥接点只观察自身父页面导航项的公开`leftItemsSupplementBackButton`属性，框架更新时同步将true校正为false，让已有纸感leading控件替换系统返回项。定向setter探针证明，出现时异步设置、布局回调及一次桥接更新均可能被随后SwiftUI工具栏配置覆盖，真实UI回归已捕获三个按钮。观察限定在页面出现期间，离开时移除；回调不捕获控制器、不启动任务、不轮询，已为false时不重复设置。额外回归验证Header移除后探针释放，原导航项可再由其他拥有方配置。保留现有代理的根页保护、按钮回调和系统pop，不增加页面级拖动、私有API、数据读取或高频输入任务。旧规格中强制隐藏返回标志的实现条款随本delta修订，单一纸感外观及返回行为要求保持。

10. **输入装饰不参与命中。** iOS17.4最大字号的正常独立进程中，启用且位于当前窗口的计划名称框中心命中外侧描边Shape，实际点击后未获得焦点。只临时禁用该Shape交互后，同一点命中UITextField并成为第一响应者；外框与1pt描边范围吻合。计划新建和基础信息编辑的名称／备注描边明确不参与命中，保留原生编辑和现有保存流程；不增加模拟点击、焦点轮询或自绘输入。恢复对照因调试表达式错误无效，未作为A-B-A证据，临时进程已停止。最终以源码编译后的实际中心触控与原UI回归验证。
11. **独立备注固定页头并滚动正文。** 同一正常进程的最大字号备注页在中等高度及软件键盘出现后均裁切标题，计数和清空超出可见范围。沿用原PaperSheetHeader，将正文放入ScrollView，辅助功能字号使用large detent，普通字号保留medium/large。局部NavigationStack隐藏系统导航栏，仅承接已有原生keyboard toolbar；收键盘不提交草稿。保留200字限制、归一化与所有保存／取消回调。

## Risks / Trade-offs

- 新字体描述值与现有 Text 拼接或显式 Font 返回类型不兼容 → 编译发现具体调用，保留语义只修接入点，不做无关重构。
- 自定义字体被二次缩放、计划详情已有预缩放 → 固定最终字体尺寸并移除重复路径，测试中文与两类等宽来源。
- 大字导致菜单越界、训练格裁切或键盘遮挡 → 连同容器尺寸与布局验证，不能依赖缩回小字号放行。
- 单个控件通过不代表完整 VoiceOver 主路径 → 定向语义与真实读屏验收分开记录，后者仍是最终门禁。
- 字体变化可能增加布局开销 → 不新增历史读取、字体注册或输入热路径任务；S4 比较当前候选 trace。

## Migration Plan

先添加能复现固定字体的测量回归，再修公共字体；随后处理色值、语义和容器，按受影响行为复用固定模拟器验证。每批记录默认／放大渲染与实际操作。无服务端部署或数据库迁移；回退本次界面变更即可。S1 已验证源码快照与证据保持独立，不将其 Release 编译冒充后续 S2 源码的最终验证。
