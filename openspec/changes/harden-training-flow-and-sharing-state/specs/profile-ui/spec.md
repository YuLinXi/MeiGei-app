# Spec Delta

## ADDED Requirements

### Requirement: 可选消耗估算的配置状态

训练偏好 SHALL 将消耗估算作为可选展示：没有有效估算体重时开关显示关闭，体重行使用未设置或可选说明，MUST NOT 将体重称为记录训练所必填。显式开启且尚无体重时 SHALL 打开配置；只有保存有效配置后才启用。取消保持原状态，单独编辑体重保留编辑前可见的开关选择。配置继续仅存本机，不改变估算算法或历史统计口径。

#### Scenario: 初次尚无估算体重
- **WHEN** 用户没有设置有效估算体重并打开训练偏好
- **THEN** 消耗估算开关显示关闭且仍可操作
- **AND** 体重行显示未设置或可选说明，不显示红色必填
- **AND** 无体重不阻止记录与完成训练

#### Scenario: 显式开启后保存体重
- **WHEN** 用户在缺少体重时打开估算开关并保存有效体重
- **THEN** 开关才变为开启，后续详情与海报继续按既有估算规则展示
- **AND** 配置不上传到后端或写入 HealthKit 能量

#### Scenario: 取消开启配置
- **WHEN** 用户打开估算开关后在体重配置中取消
- **THEN** 开关仍关闭，原体重与本地配置不因取消被改写

#### Scenario: 关闭后保留体重
- **WHEN** 用户已有有效体重并关闭消耗估算
- **THEN** 详情与海报不展示估算，已保存体重保留供未来使用

#### Scenario: 关闭时单独编辑体重
- **WHEN** 开关显示关闭且用户从体重行进入编辑后保存
- **THEN** 体重更新而开关仍关闭
- **AND** 不因先前缺省配置值自动启用估算

#### Scenario: 开启时单独编辑体重
- **WHEN** 开关已开启且用户从体重行保存新的有效体重
- **THEN** 体重更新而开关保持开启

#### Scenario: 无效输入不改变配置
- **WHEN** 用户输入空白、非数字或超出既有有效范围的体重
- **THEN** 页面不允许提交该无效值并提供可理解说明
- **AND** 取消后原体重与开关状态保持不变
