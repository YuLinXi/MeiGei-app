# Spec Delta

## ADDED Requirements

### Requirement: 自定义动作提交失败恢复

创建与删除自定义动作 SHALL 以本地可靠保存为成功边界。失败 MUST 保留创建表单或恢复可访问的原动作，不显示成功，不遗留失败创建的副本；重试成功 SHALL 只提交一次，并保持历史训练和已有计划的原引用规则。

#### Scenario: 创建保存失败后重试
- **WHEN** 用户创建自定义动作而保存失败
- **THEN** 创建表单和输入保留，显示失败，不出现残留动作
- **AND** 重试成功仅创建一个动作，保存成功后才关闭表单

#### Scenario: 删除保存失败
- **WHEN** 用户删除自定义动作而保存失败
- **THEN** 原动作仍可访问，并提供失败与重试反馈
- **AND** 不因失败宣称删除成功或影响已有历史与计划

### Requirement: 历史动作身份迁移可靠完成

同名动作身份迁移 SHALL 仅在读取及所需保存成功后记录完成标记。失败 MUST 保留可重试状态，恢复本次改挂但未可靠保存的引用，不影响其他编辑。已完成迁移 SHALL 保留现有快速跳过路径，避免每次启动完整读取历史。

#### Scenario: 迁移读取或保存失败
- **WHEN** 一次性身份迁移读取或保存失败
- **THEN** 不写完成标记，不将未保存的改挂误认为完成
- **AND** 后续重试仍能处理相同待迁移条目

#### Scenario: 已完成迁移不重复扫描
- **WHEN** 已有有效完成标记时再次启动
- **THEN** 直接跳过迁移，不新增完整历史扫描
