# 人物与画面规范

## Reference 优先级

发生冲突时严格按以下顺序判断：

1. 人物身份：`art/exercise-static/references/approved/character-v1.png`
2. 当前动作与器械：`art/exercise-static/briefs/<CODE>.json`
3. 画面语言：`art/exercise-static/references/approved/style-v1.png`
4. 同动作族已发布母版：只用于保持器械族和构图连续性
5. 外部资料：只提取动作与器械事实，不继承人物和美术风格

同时阅读 `art/exercise-static/briefs/character-v1.md` 和 `style-v1.md`。不得用单张历史动作图反向覆盖统一人物标准。

## 人物锁定

- 使用同一名原创成年男性：28–35 岁观感、略长椭圆脸、清晰但不过方的下颌、短深色低渐变发型、无胡须。
- 保持自然健壮、肩宽腰窄、真实四肢比例；不得变成健美赛夸张体型。
- 保持相同灰阶皮肤、面部、发型、肌肉量和纯黑无 Logo 训练短裤。
- 默认赤脚。只有动作 brief、器械安全性或用户明确确认要求穿鞋时才使用统一的简洁训练鞋。
- 不出现首饰、护具、纹身、品牌、不同肤色、不同人物或明显乳头/乳晕特征。
- 每张图检查肢体数量、关节朝向、左右关系、手指、脚趾和躯干连续性，拒绝扭曲或融合。

## 画面锁定

- 使用高质量灰阶医学健身插画、细腻 graphite/ink 线稿、克制软阴影和轻微纸张纹理。
- 背景固定为暖白 `#F6F3EC`，不出现真实健身房、装饰边框、文字、标签、箭头、Logo 或水印。
- 主动肌使用朱砂红 `#E8482E`，协同肌使用更浅、低饱和红，其余人体保持灰阶。
- 器械使用浅灰金属、深灰软垫和黑色配重；结构清楚但不出现品牌。
- 完整展示辨认动作所需的人物、器械、负重、附件和接触点，保留至少约 8% 安全边距。
- 采用能看清动作差异的弱透视视角，不机械固定为正面或 45°。需要区分朝向、握法或绳路时，以可验证这些关系的视角优先。
- 288×288 和约 104pt 双列卡片下，优先辨认动作与器械，其次辨认目标肌。

## 动作与器械硬约束

- 选择最能区分相邻动作的代表阶段。若终点会遮挡接触关系，可展示起始或中间阶段。
- 明确运动方向，例如腿屈伸由下往上、坐姿腿弯举由上往下；姿势和滚筒位置必须共同表达方向。
- 手掌朝向、握距、闭合握法和附件类型必须与 brief 一致。对握必须表现为掌心相对。
- 手必须实际包住把手；把手不得穿过手掌，左右手与把手应符合器械轴线和对称关系。
- 钢索从滑轮到连接套、扣环、附件必须是一条受力连续路径；受力段保持绷直，不凭空中断或弯折。
- 杠铃杆、地雷管、V-bar、绳柄、直杆和中立握把不得互相替代。
- 杠铃片必须挂在真实装片杆上；双侧器械的装片位置、数量和连接结构应对称。
- 坐垫、胸垫、靠背、腿挡、膝挡、脚踏、滚筒和手臂挡板必须位于真实接触面，不得穿过身体或承担错误用途。
- 人物必须面向应当面对的器械；镜头视角与人物朝向分开描述，避免“正面”歧义。

## 生成 Prompt 必含信息

- `exerciseCode` 和中文全称
- 当前动作的唯一变体与代表阶段
- 摄影视角、人物朝向、运动方向和安全边距
- 器械族、关键结构、负重方式和附件样式
- 双手/单手握法、掌心方向、肘路、脚位和身体接触点
- 主动肌、协同肌及其颜色层级
- `character-v1` 与 `style-v1` 的锁定要求
- 当前动作最常见的拒绝项

不要只写动作名称。名称不足以稳定生成准确器械和人体关系。
