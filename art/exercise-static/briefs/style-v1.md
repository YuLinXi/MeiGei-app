# `style-v1` 视觉风格 brief

## 来源与用途

`style-v1.png` 来自项目所有者此前明确批准的 `PEC_DECK_FLY` 效果图 1。它只定义视觉语言和器械构图标准，不定义人物身份；后续生成时人物的脸型、发型、体型和服装必须以 `character-v1.png` 为最高优先级。

原图仅使用本项目原创文字 prompt 生成，没有第三方图片输入。原始 SHA-256 为 `2b5d5158559ee71953eeb57cc88b7a427c2bbcf9d3b77cc9f73a491888376ec0`。

## 锁定项

- 高质量灰阶医学健身插画，细腻 graphite/ink 线稿和克制的软阴影。
- 主动肌使用朱砂红 `#E8482E`，协同肌使用更浅、更低饱和的红色，其余人体保持灰阶。
- 器械使用浅灰金属、深灰软垫和黑色配重，不出现品牌元素。
- 背景固定为暖白 `#F6F3EC`，无健身房环境、文字、Logo、水印、标签和箭头。
- 全身与关键器械完整入画，弱透视或近似正交的 45° 前侧视角，主体清晰且保留安全边距。
- 288×288 与真实双列卡片下仍能首先识别动作与器械，其次识别目标肌。
- 男性胸部只表达胸大肌的肌纤维与体块，乳头/乳晕轮廓必须极弱、低对比或不可见，不得形成深色圆点、明显凸起或视觉焦点。

## 不得从 `style-v1.png` 继承

- 图中旧人物的脸型、发型、体型或身份特征。
- 仅属于蝴蝶机的器械结构，用于其他动作时必须替换为对应动作器械。
- 旧图中任何可能与新动作 brief 冲突的握法、姿势或接触点。

## Reference 优先级

1. 人物身份：`character-v1.png`。
2. 当前动作和器械：对应动作 brief。
3. 线稿、色板、背景、阴影和构图语言：`style-v1.png`。

当多个 reference 发生冲突时必须遵循以上顺序，不得为了复刻风格图而换脸。
